Customer Value Intelligence System (CLV + RFM)

A customer analytics system that turns raw transaction behavior into segments, value signals, and targeting recommendations for marketing and retention.

GitHub Repo Contact
Business goal: stop treating all customers the same. Identify who to retain, who to upsell, and who to re-activate.

Problem

Teams needed a practical way to prioritize customers (not just total revenue), and to run campaigns that match customer behavior and value.

Approach

  • Built RFM features to represent behavior
  • Segmented customers using clustering
  • Created segment-level KPIs and targeting rules
  • Packaged outputs for BI / stakeholder use

Outputs

  • Customer segments with clear personas
  • Value signals for prioritization
  • Campaign recommendations by segment

Tech Stack

  • SQL, Python, Pandas
  • scikit-learn (clustering)
  • Dashboard-friendly outputs
