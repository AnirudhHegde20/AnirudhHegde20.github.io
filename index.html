Business Problem

AI SaaS Retention & Competitive Intelligence Platform

B2C AI apps lose most users in their first month. This project asks: what early signals predict whether a user will stick around, and how do we build a metrics layer product teams can actually trust?

What I Built

End-to-end analytics engineering pipeline ingesting 500K+ behavioural records and Product Hunt API data into a layered PostgreSQL warehouse using dbt Core, modelling raw data into staging models and analytics-ready marts.

Key Decisions & Challenges

Chose dbt for transformation to enforce modular, testable SQL over ad hoc scripts. Designed 42 automated tests with GitHub Actions CI to catch data issues before they reached dashboards.

What I Learned

Warehouse layering is not just architecture. It is discipline. The 8x survival gap between Power Users and New Users was only visible because cohort definitions were consistent across the pipeline.

Business Problem

E-commerce Conversion Optimisation

A product team wants to ship a new page design. Overall conversion looks similar between variants, but the real question is whether rollout is safe across every region and device segment.

What I Built

A/B test framework for 2,000 users using Chi-Square and Fisher's Exact tests across region and device segments. Built segment interaction analysis that surfaced a critical failure case the overall numbers masked.

Key Decisions & Challenges

The overall Chi-Square test showed p=0.33, but segment-level Fisher's Exact tests revealed Europe + Tablet had conversion drop from 18.4% to 0% (p=0.0151). Built confidence intervals for all segments to support a targeted rollout recommendation.

What I Learned

Never stop at the aggregate result. The most important finding in this project was invisible until segment analysis.
